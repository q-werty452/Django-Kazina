# 🍽 Казына — Сайт ресторана

Сайт ресторана **«Казына»** — кыргызская кухня с этническим дизайном.
Построен на Django + django-unfold с кастомной тёмно-зелёной админкой в золотом стиле.

---

## Стек

- **Python 3.13**
- **Django 6.0**
- **django-unfold** — кастомная тема админки
- **Pillow** — загрузка изображений
- **SQLite** — база данных (по умолчанию)

---

## Быстрый старт

### 1. Клонировать репозиторий

```bash
git clone <ссылка на репозиторий>
cd Django-Kazina
```

### 2. Создать виртуальное окружение

```bash
python -m venv venv

# Windows
venv\Scripts\activate

# macOS / Linux
source venv/bin/activate
```

### 3. Установить зависимости

```bash
pip install -r requirements.txt
```

### 4. Применить миграции

```bash
python manage.py migrate
```

### 5. Создать суперпользователя

```bash
python manage.py createsuperuser
```

### 6. Запустить сервер

```bash
python manage.py runserver
```

Сайт откроется на [http://127.0.0.1:8000](http://127.0.0.1:8000)
Админка: [http://127.0.0.1:8000/admin](http://127.0.0.1:8000/admin)

## Модели (что можно редактировать в админке)

| Модель | Описание |
|---|---|
| `Category` | Категории меню (Выпечки, Блюда, Супы и т.д.) |
| `MenuItem` | Блюда — название, цена, фото, описание, бейдж, флаг «Блюдо недели» |
| `Hall` | Залы ресторана с фото и описанием |
| `GalleryImage` | Фотогалерея атмосферы |
| `SliderSlide` | Слайды главного баннера |
| `SiteSettings` | Телефон, адрес, WhatsApp, соцсети, карта, текст «О нас» |
